# seizure-detection-watch-demo
🧠 This project is designed to help detect seizures in epilepsy patients using wearable devices such as the Apple Watch. The app leverages machine learning models to predict seizure events, giving users enough time to take preventive measures. It is intended for educational purposes and is not for commercial use.

## Features

- **Seizure Prediction**: Uses a machine learning model to predict potential seizures based on health data.
- **Apple Watch Integration**: Works seamlessly with the Apple Watch to track vital signs such as heart rate, which can help in predicting seizures.
- **HealthKit Integration**: Utilizes HealthKit to gather relevant health data, such as heart rate and other fitness metrics.
- **Real-time Monitoring**: Continuously monitors the user's health and provides real-time alerts.

## Technologies Used

- **Swift & SwiftUI**

- **HealthKit** 

- **CoreMotion** 

- **CoreML** 


## Installation

1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/yourusername/seizure-detection-app.git
   ```

2. Open the project in Xcode.

3. Build and run the app on a compatible Apple Watch or simulator.

## Usage

1. Launch the app on your Apple Watch.
2. The app will start monitoring your health metrics in real time.
3. If a seizure is predicted, an alert will be triggered, allowing you to take necessary actions.
